# AI-NeckRehab — تأهيل الرقبة لدى لاعبي الفنون القتالية (أداة مساندة لأطروحة)

خمس واجهات (قائمة جانبية، تتطلب Streamlit ≥ 1.37):

1. **القياسات:** اللاعبون والمجموعات، إدخال القياسات T0–T3 يدويًا، **استيراد من Excel/CSV** (قالب جاهز)، جدول البيانات، نسخ احتياطي.
2. **الاختبارات:** القوة العضلية · المدى الحركي (كاميرا بث مباشر أو فيديو) **مع الخوف الحركي من الفيديو نفسه** + استبيان TSK-11 ·
   الألم (0–10، مع استيراد Excel) · EMG (استيراد Excel) · سرعة الاستجابة الحركية (كاميرا مباشرة).
3. **البرنامج التأهيلي:** يولّده النظام لكل لاعب حسب نتائج اختباراته: 8 أسابيع × 3 وحدات، 15–90 دقيقة، من السهل إلى الصعب.
4. **تطبيق التمارين بالكاميرا:** بث مباشر يعرض الوصف الحركي الصحيح ويؤشر عند الخطأ، ويحدّد المدى المستهدف بالدرجات.
5. **الإحصاء:** معلمي ولا معلمي وتلقائي، بديل كامل عن SPSS (مقارنات، قياسات متكررة، تصميم مختلط، ANCOVA، ارتباط وانحدار، حجم عينة).

## التشغيل
```
pip install -r requirements.txt
streamlit run app.py
```
قاعدة البيانات: `data/neck_rehab_v2.db` (تُنشأ تلقائيًا).

## ما الذي يعتمد على الذكاء الاصطناعي؟
- **BlazePose** (شبكة CNN مدرَّبة مسبقًا): تتبع الرأس والكتفين للمدى والمدرّب المباشر واختبار الاستجابة.
- **EMG-Net** (CNN أحادية البعد): تصنيف جودة النشاط العضلي (مدرَّبة هنا على بيانات تركيبية للعرض فقط؛ درّبها على بيانات موسومة).
- **مولّد البرنامج الفردي:** نظام خبير قائم على قواعد سريرية قابلة للتعديل (ليس تعلّمًا آليًا). صِفه في الأطروحة بدقة.

## تنبيهات مهمة
1. زوايا الكاميرا 2D تقريبية (خطأ قد يبلغ 5–10°) والدوران أقل دقة؛ أثبت الصلاحية مقابل جونيومتر أو IMU (ICC وBland–Altman).
2. **مؤشر الحذر الحركي** من الفيديو سلوكي تجريبي لم تثبت صلاحيته مقابل TSK-11؛ يُستخدم للمقارنة وليس بديلًا عن الاستبيان.
3. زمن الاستجابة الحركية يتضمن تأخر الكاميرا والعرض (100–300 ms)؛ يصلح للمقارنة بين T0 وT3 بالجهاز نفسه.
4. عتبات البرنامج الفردي مبدئية وتُعتمد مع المشرف والأخصائي؛ والبرنامج اقتراح وليس وصفة علاجية.
5. البث المباشر (WebRTC) قد يتأخر على Streamlit Cloud؛ يُفضَّل التشغيل محليًا أثناء التجربة. التبويبات الأخرى لا تحتاجه.
6. على Streamlit Cloud التخزين مؤقت: نزّل نسخة احتياطية بعد كل جلسة.
